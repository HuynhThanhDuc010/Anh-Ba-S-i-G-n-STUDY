# Anh Ba Saigon Studies

Project source code đã được tách từ bản app hiện tại để dễ chỉnh sửa bằng VS Code.

## Cấu trúc

- `index.html` — giao diện HTML
- `styles.css` — toàn bộ CSS
- `app.js` — toàn bộ JavaScript và logic app
- `assets/dragon_logo.png` — logo rồng
- `assets/Anh_Ba_Saigon_Studies.ico` — icon Windows nếu có
- `.vscode/settings.json` — cấu hình VS Code cơ bản

## Cách mở bằng VS Code

1. Giải nén thư mục.
2. Mở VS Code.
3. Chọn **File → Open Folder...**
4. Chọn thư mục `Anh_Ba_Saigon_Studies_Source`.
5. Mở `index.html`.

### Cách chạy khuyên dùng

Cài extension **Live Server** trong VS Code, sau đó:
- Chuột phải `index.html`
- Chọn **Open with Live Server**

App vẫn dùng `localStorage`, nên dữ liệu được lưu theo trình duyệt/domain đang chạy.

## Ghi chú

Không đổi tên các file `index.html`, `styles.css`, `app.js` nếu chưa sửa lại đường dẫn tương ứng trong HTML.


## Cài icon Desktop
Giải nén toàn bộ ZIP rồi chạy `Tao_shortcut_Desktop.bat`.
